This guide walks you through creating your first server-client network with Networker. By the end, you'll have a server that exposes methods to clients and a client that fires those methods — the core pattern used for all Networker communication.

<Note>
`NetworkerServer` can only be created on the server. `NetworkerClient` can only be created on the client. Attempting to create either on the wrong context will throw an error.
</Note>

## What you'll build

You'll create a simple service called `myService` on the server that accepts calls from clients. The client will be able to call `printTest`, which logs the player's name on the server.

<Tabs>
  <Tab title="Server">
    ```luau myService.server.luau
    local Networker = require(game.ReplicatedStorage.Packages.networker)

    local myService = {}

    function myService:init()
        -- Initialize networker for this service.
        -- Only methods listed in the third argument can be called by clients.
        self.networker = Networker.server.new("myService", self, {
            self.printTest,
        })
    end

    -- Clients can call this because it's listed in the clientAccess table.
    -- The first argument is always the Player who fired the event.
    function myService:printTest(player: Player)
        print(`{player.Name} called the print test`)
    end

    -- This method is NOT accessible to clients — it's not in the access table.
    function myService:addPoints(player: Player, points: number)
        -- server-only logic
    end

    return myService
    ```
  </Tab>
  <Tab title="Client">
    ```luau myService.client.luau
    local Networker = require(game.ReplicatedStorage.Packages.networker)

    local serviceClient = {}

    -- Connect to the server networker using the same tag: "myService"
    local networker = Networker.client.new("myService", serviceClient)

    -- Fire the "printTest" method on the server (one-way, no return value)
    networker:fire("printTest")
    ```
  </Tab>
</Tabs>

## Step-by-step walkthrough

<Steps>
  <Step title="Create the server networker">
    Call `Networker.server.new()` with three arguments:

    1. **`networkTag`** — a unique string that both sides use to identify this networker (`"myService"`)
    2. **`module`** — the table/class whose methods the client can call (`self`)
    3. **`clientAccess`** — an array of method references the client is **allowed** to call (`{ self.printTest }`)

    Any method not listed in `clientAccess` is automatically blocked. If a client tries to call `addPoints`, Networker will log a warning and ignore the call.

    ```luau
    self.networker = Networker.server.new("myService", self, {
        self.printTest,
    })
    ```
  </Step>
  <Step title="Define accessible methods">
    Server methods called by clients always receive the `Player` as the first argument, followed by any additional arguments the client passed.

    ```luau
    function myService:printTest(player: Player)
        print(`{player.Name} called the print test`)
    end
    ```
  </Step>
  <Step title="Connect from the client">
    On the client, call `Networker.client.new()` with the same tag (`"myService"`) and your client module. Networker automatically finds the matching remotes folder.

    ```luau
    local networker = Networker.client.new("myService", serviceClient)
    ```
  </Step>
  <Step title="Fire methods to the server">
    Use `:fire()` to call a server method by name. This is one-way — the call doesn't wait for a return value.

    ```luau
    networker:fire("printTest")
    ```

    To call a server method and **await a return value**, use `:fetch()` instead. This yields the current thread until the server responds.

    ```luau
    local result = networker:fetch("getPlayerData")
    ```
  </Step>
</Steps>

## Firing from the server to clients

The server can also push events to clients. Use `:fireAll()` to send a message to every connected player:

```luau
-- Server: tell all clients to show a notification
self.networker:fireAll("showNotification", "The game starts in 10 seconds!")
```

On the client, incoming server events are routed to methods on the `module` you passed to `Networker.client.new()`:

```luau
local serviceClient = {}

-- This method is called when the server fires "showNotification"
function serviceClient:showNotification(message: string)
    print("Notification:", message)
end

local networker = Networker.client.new("myService", serviceClient)
```

<Tip>
The method name the server fires must match exactly the method name on the client module. Networker routes calls by string name.
</Tip>
