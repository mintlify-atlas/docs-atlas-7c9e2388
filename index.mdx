Networker replaces the boilerplate of raw `RemoteEvent` and `RemoteFunction` instances with a structured API that handles routing, access control, and data synchronization between your Roblox server and clients. Define which methods clients can call, fire events to targeted player groups, and sync values — all with a consistent interface on both sides.

## How it works

Networker wraps Roblox's underlying `RemoteEvent` and `RemoteFunction` instances behind two classes — `NetworkerServer` (server-side) and `NetworkerClient` (client-side). You give each networker a unique tag, and the library automatically manages the remote instances and routes method calls between the two sides.

<Steps>
  <Step title="Install via Wally">
    Add `leifstout/networker` to your `wally.toml` dependencies and run `wally install`.
  </Step>
  <Step title="Create a server networker">
    Call `Networker.server.new()` with a tag, your service module, and a list of methods clients are allowed to invoke.
  </Step>
  <Step title="Create a client networker">
    Call `Networker.client.new()` with the same tag and your client module. The client connects automatically.
  </Step>
  <Step title="Fire and fetch">
    Use `:fire()` from the client to call server methods, `:fireAll()` from the server to broadcast, and `:fetch()` for request/response patterns.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Access control" icon="shield-check">
    Whitelist exactly which server methods clients are allowed to call — any unlisted method is silently blocked.
  </Card>
  <Card title="Targeted firing" icon="bullseye">
    Fire events to a single player, a list, all players, or all players except a group — with one method call.
  </Card>
  <Card title="Recipient groups" icon="users">
    Maintain a persistent list of recipients and broadcast to them with `:fireRecipients()`.
  </Card>
  <Card title="Data sync" icon="arrows-rotate">
    Push values to clients with `:set()` and `:setAll()`, then react to changes using `getServerChangedSignal()`.
  </Card>
  <Card title="Instance networking" icon="cube">
    Pass a Roblox `Instance` as the network tag to automatically bind and clean up networking when the instance is destroyed.
  </Card>
  <Card title="Request/response" icon="arrow-right-arrow-left">
    Use `:fetch()` on the client to invoke a server method and await its return value via `RemoteFunction`.
  </Card>
</CardGroup>
